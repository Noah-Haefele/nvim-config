# Neovim Config
My personal Neovim configuration.

## Installation
Neovim >= 0.11 is required.

### 1. Clone the config

```bash
git clone https://github.com/Noah-Haefele/nvim-config.git ~/.config/nvim
```

### 2. Install Packer

```bash
git clone --depth 1 https://github.com/wbthomason/packer.nvim ~/.local/share/nvim/site/pack/packer/opt/packer.nvim
```

### 3. Start Neovim

```bash
nvim
```

Then run `:PackerSync` inside of Neovim
